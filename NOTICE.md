## Echo-Loop (no code retained)

TingLang's learning method (close listening, shadowing, blind listening,
retelling, spaced review) follows Echo-Loop (`echo-loop/Echo-Loop`, AGPL-3.0).
An early development version adapted one Echo-Loop file (the timed sentence
model); it was replaced by an independent implementation, and this source
tree contains no Echo-Loop code. The JSON field names of timed cues (`index`,
`text`, `startTime`, `endTime`, `isBookmarked`) are kept so courses in that
shape still load.

No Echo-Loop branding, accounts, subscriptions, telemetry, remote catalogue,
update service, learning plan/FSRS code, database schema or pronunciation
pipeline is included.

## English-format compatibility

The course adapter reads the English V3 course format (`schema_version: 2` /
`design_version: 3`), a JSON course format by the same author. No learner
records, private courses, recordings, vocabulary assets or credentials are part
of this distribution, and access to a course is not assumed to license its
third-party media for redistribution.

check `api/openapi.yaml`; it is not part of the app.

## sherpa-onnx runtime (Apache-2.0)

The app links the `sherpa_onnx` Flutter package, version 1.13.8
(https://github.com/k2-fsa/sherpa-onnx, Copyright (c) 2022–2026 Xiaomi
Corporation and the k2-fsa contributors, Apache License 2.0,
https://www.apache.org/licenses/LICENSE-2.0). Its macOS package ships
`libsherpa-onnx-c-api.dylib` (built with onnxruntime, MIT,
https://github.com/microsoft/onnxruntime), which is embedded in the app bundle
unmodified. Tinglang's Dart code calls it through the package's bindings; no
sherpa-onnx source is copied into this repository.
