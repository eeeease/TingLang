# tinglang_native_windows

C++ Flutter plugin skeleton for Windows. It builds a plugin DLL that registers
nothing yet. Milestone M8 adds WASAPI process/endpoint loopback, microphone
capture, Media Foundation decoding, a layered always-on-top DirectWrite caption
window and `RegisterHotKey`, behind a Pigeon C++ host API.

Not compiled in M1: this repository has only been built on macOS.
